# Asset provenance

## Public application

- Interface: project-authored HTML and CSS; no UI kit, template, stock asset, or copied website.
- Logo mark: CSS-only geometric mark authored for DungeonQ.
- Typography: local operating-system font stacks only; no downloaded web fonts.
- Scenario Packs: project-authored fixed-seed synthetic fixtures. They contain no real tenant, host, credential, log, or customer data.
- Repository screenshots: captured directly from the local DungeonQ release candidate at 1280×720, 1280px full-page, and 390×844; no third-party content or post-composited asset.
- Icons and illustrations: none.
- Browser scripts: project-authored modules plus no remote runtime script.

## Demo media

Screenshots and screen recordings must be captured from the public DungeonQ app. Narration, captions, music, and any additional visual asset will be listed here before public video release. Until then, no external demo-media asset is part of this source release.
